<h2>稳不稳定，看六个参数就够了</h2>
<p>「稳定吗」这个问题很难用一句话回答，因为稳定是多个参数共同作用的结果。把参数拆开看：地址是否独享、是否静态、带宽是否被抢占、线路是否抖动、有没有健康保障、以及服务商是否真在运维。</p>
<p>六个参数里，前三个决定「会不会出问题」，后三个决定「出问题之后怎么样」。两者都重要，只看前者容易买到「平时正常、出事没人管」的资源。</p>

<h2>参数一：是否独享</h2>
<p>共享资源的不稳定不来自技术，来自「别人」。同段有人跑批量任务，整段的延迟会一起抬升；有人频繁触发验证，整段的评价会一起下降。这些你都控制不了。</p>
<p>判断方法：直接问是否独享，看回答是否明确、是否愿意写进条款。回答「基本没人用」这类模糊表述的，按共享对待。</p>

<h2>参数二：静态还是动态</h2>
<p>动态地址会变化，变化本身不算「不稳定」，但如果你的环境绑定了地址，地址一变就等于环境失效。从使用者角度，这就是不稳定。</p>
<p>所以要分清「网络不稳」和「地址变了」。前者是质量问题，后者是产品属性，购买前要确认清楚自己买的哪种。</p>

<h2>参数三：带宽是否被抢占</h2>
<p>一条线路的总带宽是固定的，多人共用就会抢。表现是「某些时段明显变慢」，尤其集中在当地晚间。判断方法是连续几天在同一时段测速，看有没有规律性的下降。</p>
<p>有规律说明是带宽竞争，没规律说明是线路抖动。两种成因的处置方式完全不同，先分清再谈更换。</p>

<h2>参数四到六：出问题之后的三件事</h2>
<p>健康保障指「地址不可用时多久给替换」。有明确时效的，中断时间可控；没有的，只能等。运维响应指「能不能定位到原因」，只会说「重启试试」的，等于没有运维。</p>
<p>第三项是合同条款。「什么情况下可以终止、能不能退款」这一类，在报价单上通常没有，但它决定了你在最坏情况下的退路。</p>

<h2>为什么住宅线路天生比机房更容易抖</h2>
<p>因为它的承载环境是真实家庭：电力、设备、本地网络都可能波动。这不是服务商能完全消除的，只能通过冗余和监控降低影响。</p>
<p>理解这一点，就不会把「偶发波动」当成质量事故。真正该关注的是「波动的频率和恢复速度」，而不是「有没有波动」。</p>

<h2>购买时要问的五个问题</h2>
<p>一，这条地址是否独享，同段还有没有别人。二，是静态还是动态，续费是否保持原地址。三，上行带宽多少，能不能实测。四，出现不可用时多久给替换。五，有没有可用的性能监控或日志。</p>
<p>五个问题都不涉及技术细节，但回答的具体程度，基本能反映这家服务商的实际水平。</p>

<h2>验收阶段怎么测稳定性</h2>
<p>连测七天，每天固定两个时段，其中一次放在当地晚高峰。记录延迟、丢包、出口地址三项。七天之后看趋势：延迟是否平稳、丢包是否偶发、地址是否变化。</p>
<p>单次测试说明不了问题，只有连续观测才能区分「偶发」和「常态」。这一步花的七天，能省掉后面几个月的反复折腾。</p>

<h2>常见问答</h2>
<h3>双 ISP 住宅线路会比机房线路不稳定吗？</h3>
<p><strong>答：</strong>波动概率更高，这是承载环境决定的。但波动幅度和恢复速度要看具体线路。</p>
<h3>偶尔掉线正常吗？</h3>
<p><strong>答：</strong>偶发属于正常范围，关键看频率。一天几次属于异常，一周一两次可以接受。</p>
<h3>稳定性可以靠配置提升吗？</h3>
<p><strong>答：</strong>能提升一部分，比如健康检测与自动切换，但根本还是取决于线路质量。</p>
<h3>买之前能测稳定性吗？</h3>
<p><strong>答：</strong>短期试用能看个大概，长期表现需要时间验证。所以先小量买、跑一段再加量更稳妥。</p>
